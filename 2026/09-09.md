# 2026-09-09

- STT 프록시 구현 시 클라이언트가 보낸 `model`, `speechContexts` 같은 인식 옵션을 외부 음성 인식 API 요청에 그대로 전달해야 한다. 프록시에서 필드가 누락되면 인식 모델·힌트 단어가 적용되지 않아 정확도가 조용히 떨어진다.
- 모바일용 TTS 음성 합성 프록시 엔드포인트(Spring Boot)를 추가하고, 합성 결과를 S3에 캐시한 뒤 presigned URL로 반환하는 패턴을 적용했다. 동일 텍스트 재요청 시 외부 API 호출 비용을 줄이고, 바이너리를 서버가 직접 스트리밍하지 않아 부하도 분산된다.
- 캐시 도입 시 히트/미스 여부와 단계별(캐시 조회·외부 합성·S3 업로드·URL 발급) 소요 시간을 로그로 남겨두면 캐시 효과와 병목 구간을 수치로 확인할 수 있다.
