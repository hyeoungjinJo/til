# 2026-10-22

- 인증 전 단계의 전화번호 조회 API는 응답에 개인정보를 그대로 노출하지 않는다. 마스킹해서 내려줘야 계정 존재 여부 탐색이나 정보 유출을 줄일 수 있다.
- S3 자격증명은 정적 액세스 키가 비어 있으면 IRSA(IAM Roles for Service Accounts)로 받도록 fallback 구성한다. ServiceAccount에 환경별 IAM Role을 연결하면 키 없이 Pod 단위로 권한을 분리할 수 있다.
- S3 Presigner가 전용 키로 서명하는지 IRSA 기본 자격증명으로 서명하는지 기동 로그에 남긴다. 자격증명 출처를 바로 알 수 있어 서명 오류를 디버깅할 때 도움이 된다.
- 운영 브랜치 핫픽스를 개발 브랜치에 백포트할 때 Flyway 같은 DB 마이그레이션 버전 번호가 충돌하면, 해당 스크립트를 다음 빈 버전으로 옮겨 순서를 맞춘다.
- Dependabot을 설정해 Gradle 의존성과 GitHub Actions 워크플로의 취약점·업데이트를 자동으로 점검하게 한다.
