## 백엔드 (Spring Boot / JPA·QueryDSL)
- 애플리케이션 리포에서 운영 도구·인프라 형상·인증 문서를 별도 리포로 분리하고, `.dockerignore`로 도커 빌드 컨텍스트를 JAR만 포함하도록 한정 — 리포 경계를 좁히면 빌드 컨텍스트가 가벼워지고 관심사가 분리됨
- 전 기관·전체 개인 사용내역 집계를 엔티티 로딩 대신 경량 프로젝션 기반 집계로 전환해 성능 개선. 연동 행에 대응하는 사용자가 없는 케이스에서 집계 NPE 방어 추가. 신·구 집계 경로 결과를 나란히 비교하는 대조 QA 페이지를 만들어 리팩터링 정합성 검증 — 집계 로직 교체 시 대조 페이지로 회귀 확인하는 패턴 유효
- Prometheus blackbox exporter에서 env/tier 같은 구분값은 타깃 라벨이 아니라 메트릭 relabel(`additionalMetricsRelabels`)로 부여해야 메트릭 쿼리에서 일관되게 필터 가능
- ALB 뒤에 Kibana를 둘 때 헬스체크 경로는 인증 없이 응답하는 `/login` 같은 경로로 지정해야 함. Helm 차트 훅의 동작 함정은 발견 즉시 문서화해 재발 방지
- 모니터링 스택 첫 운영일 보정: Grafana 배포 전략을 Recreate로 변경, 클라우드 알림 룰 집계 방식 조정, Elasticsearch exporter에 필요한 최소 권한 부여 — 스택 구축 직후 실제 운영에서만 드러나는 이슈들 존재
- ISO 27001 대비 모니터링 체계 강화(알림 룰·라우팅·익스포터·운영 리포트)와 증적 문서 정비(알림 규칙, 주기적 검토, 서버 시각 동기화) — 인증 요구사항을 운영 자동화와 문서 증적으로 함께 충족
- 가입 시 전화번호를 정규화된 포맷으로 저장하도록 수정. 간편 모드에서는 특정 추천 카테고리를 제외하도록 추천 조립 로직 보완, 전용 QA 페이지로 검증
